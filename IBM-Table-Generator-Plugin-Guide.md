# IBM Table Generator - Figma Plugin Guide

## No more manual table creation! 
Generate professional, data-rich tables in your Figma designs with IBM Carbon Design System components.

---

## 🚀 **What This Plugin Does**

The IBM Table Generator transforms tedious table creation into an intelligent, automated process. Instead of manually placing components and typing data cell by cell, this plugin:

- **Scans your existing Carbon table components** and learns their structure
- **Generates realistic data** using AI, sample data, or your uploaded files
- **Creates complete tables** with proper Carbon styling, interactions, and accessibility
- **Maintains design system consistency** while saving hours of manual work


## 🎯 **To Use This Plugin**

### **Step 1: Prepare Your Design File**
- Have IBM Carbon "Data table" components available in your Figma file
- These can be from the IBM Carbon Design Kit or your own Carbon-based components
- The plugin will scan and learn from these existing components

### **Step 2: Launch & Scan**
- Open the IBM Table Generator plugin
- **Select any "Data table" component** in your design
- The plugin automatically scans and identifies:
  - Header cell templates
  - Body cell templates  
  - Row components
  - Footer/pagination elements
  - Selection and expansion components

### **Step 3: Configure Your Table**
- **Set dimensions**: Choose rows and columns (e.g., 5×10, 3×8)
- **Choose data source**:
  - 🤖 **AI Generated**: Watson AI creates contextual, realistic data
  - 📊 **Sample Data**: Faker.js generates names, emails, addresses, etc.
  - 📁 **Upload File**: Import from Excel/CSV files
  - ✏️ **Manual Entry**: Type your own custom data

### **Step 4: Customize Features**
- ✅ **Selectable rows**: Add checkboxes for row selection
- 📖 **Expandable rows**: Enable expand/collapse arrows for row selection  
- 📄 **Pagination**: Include footer with page controls
- 🏷️ **Custom content**: Set meaningful data in the cells
- 📝 **Column properties**: Set column widths, alignment, and other custom properties
- 📝 **Footer**: Add pagination controls or other footer elements

### **Step 5: Generate & Refine**
- Click **"Generate Table"** to create your complete table
- **Edit cells directly**: Click any cell to modify content
- **Bulk updates**: Select multiple cells for batch changes
- **Regenerate**: Modify settings and create new variations
